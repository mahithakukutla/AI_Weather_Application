# AI Weather Assistant

Flask application for current weather and concise AI weather advice.

## Run

1. Put an OpenWeather API key in `.env`.
2. Install dependencies: `pip install -r requirements.txt`
3. Start: `python app.py`
4. Visit `http://127.0.0.1:5000`.

`GROQ_API_KEY` is optional; the app gives a local weather tip when it is absent.
